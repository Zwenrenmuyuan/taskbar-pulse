# TaskbarPulse

**轻量级 Windows 11 任务栏监控工具，让系统状态一眼可见。**

在任务栏实时查看 CPU、GPU、内存、网速和国际金价，单击即可展开性能概览。采用 C++20、Win32、Direct2D / DirectWrite 实现，单个可执行文件约 1.3 MB，无需安装额外的应用运行时。

基本监控无需管理员权限或额外监控驱动；CPU 温度为可选功能，使用已安装的 PawnIO 驱动，需要管理员权限。

## 功能亮点

| 指标 | 显示内容 |
| --- | --- |
| CPU | 总占用率、主频；支持的 AMD Zen 处理器可读取温度 |
| GPU | 占用率、核心温度、已用 / 总显存，详细指标依赖 NVIDIA 驱动接口 |
| 内存 | 已用 / 总物理内存与占用比例 |
| 网络 | 实时上传 / 下载速率、本次运行期间的累计流量 |
| 国际金价 | 国际现货黄金人民币换算价，单位为元/克，可关闭 |
| 性能概览 | CPU、GPU、网络历史曲线，显存与内存详情，以及外观快捷切换 |

- **两种外观**：微胶囊风格支持底部迷你进度条，无框风格支持背景微波形底纹。
- **主题与缩放**：跟随系统任务栏的浅色 / 深色主题，也可手动指定；支持 Per-Monitor DPI v2 高分屏缩放。
- **清晰稳定的文字**：DirectWrite 灰度抗锯齿与等宽数字减少数值更新时的横向跳动。
- **自动避让**：识别任务栏应用图标、搜索、小组件和托盘占用区域；全屏应用覆盖任务栏时自动暂停刷新，并支持任务栏自动隐藏。
- **灵活刷新**：系统指标默认每 1 秒采样，可在菜单中切换为 0.5 秒或 2 秒；金价独立低频刷新。
- **便携使用**：配置保存在程序目录，支持开机自动启动与水平位置微调。

历史曲线保留最近 **48 个采样点**。默认刷新周期下约为 48 秒，切换刷新频率后，曲线覆盖的时间也会相应变化。

## 快速上手

运行环境为 **Windows 11 x64**，支持在**所有显示器**（主任务栏及各副屏任务栏）同时显示，也可在右键菜单中指定仅在主显示器或特定副屏显示。

1. 按照下方的[从源码构建](#从源码构建)生成 `build\TaskbarMonitor.exe`。
2. 将程序放在一个当前用户可写的固定目录，双击运行。
3. 在任务栏查看指标，单击面板打开性能概览，右键调整显示选项。

项目名称为 TaskbarPulse，当前构建产物仍使用 `TaskbarMonitor.exe`，配置文件名为 `TaskbarMonitor.ini`。

### 常用操作

| 操作 | 效果 |
| --- | --- |
| 左键单击任务栏面板或托盘图标 | 展开 / 收起性能概览 |
| 右键单击任务栏面板或托盘图标 | 打开设置菜单 |
| 按住 `Alt` 并用左键拖动任务栏面板 | 调整水平位置，松开后保存 |
| 右键 → 重置水平位置偏移 | 恢复默认位置偏好 |
| 右键 → 开机自动启动 | 启用 / 关闭当前用户登录时自动启动 |
| 右键 → 退出 | 退出程序 |

右键菜单还可切换外观、配色、进度条 / 波形底纹、GPU 温度、国际金价、显示位置（所有显示器 / 仅主显示器 / 指定副屏）及刷新频率。**CPU 副行指标**可选择主频、CPU 温度、内存占用率或隐藏。

### 配置与迁移

设置自动保存到 EXE 同目录下的 `TaskbarMonitor.ini`。移动程序时，一并复制此文件即可保留显示设置与位置偏好；恢复默认设置时，先退出程序，再删除此文件并重新运行。

开机自启单独保存在当前用户的 Windows 启动项中。移动或删除程序前，应先取消“开机自动启动”；移动后可在新位置重新启用。删除 INI 文件不会清除开机自启设置。

## 指标与兼容性

### CPU 温度

当前温度采集针对 PawnIO 签名模块支持的 **AMD Zen** 处理器，读取控制温度 **Tctl**；在 Ryzen 9 9950X 上对应 Tctl/Tdie。当前没有实现 Intel CPU 温度采集。

使用前需要系统已安装可用的 PawnIO 驱动。先退出正在运行的程序，再以管理员身份启动，然后选择 **右键 → CPU 副行指标 → 显示 CPU 温度**。性能概览会在数据可用时同时显示温度与主频。

程序不会安装驱动或自动请求提权。驱动、权限或硬件支持条件不满足时，任务栏温度显示为 `--`，其他监控功能可继续使用。

### GPU 指标

优先使用 NVIDIA `nvapi64.dll`，初始化不可用时尝试 `nvml.dll`。多张 NVIDIA 显卡同时存在时，自动选择接口报告显存容量最大的设备。

没有可用的 NVIDIA 接口时，DXGI 回退仅尝试读取显卡名称和独立显存容量，**不提供 GPU 占用率、温度或已用显存**。因此，当前不具备 AMD / Intel GPU 的完整监控能力；不可用的详细指标会显示为 `--` 或“不可用”。

### 网络统计

网速汇总当前已连接的物理网卡流量，排除回环、隧道和过滤接口，避免将虚拟过滤接口的流量重复计入。它不是单个进程的网速，也不单独统计 VPN / 虚拟网卡。

累计流量从本次程序启动后开始统计，退出后不保留。

### 国际金价

金价默认开启，通过 [Gold API](https://gold-api.com/faqs) 的免 Key 接口获取国际现货黄金人民币报价，再从元/金衡盎司换算为**元/克**。

- 启用时发起请求，之后每 **30 秒**在后台更新一次，不受系统指标刷新频率影响。
- 将鼠标悬停在托盘图标上，可查看按本地时区显示的报价更新时间。
- 获取失败时保留上次报价并标记“未更新”；尚未成功获取过报价时显示 `--`。
- 取消 **右键 → 显示国际金价（元/克）** 后隐藏该列，并停止后续请求。其他系统指标无需联网。

这里显示的是国际现货换算价，与上金所 Au99.99、银行交易报价或金店零售价不同。

### 任务栏、多显示器与远程桌面

程序支持多显示器环境下的每个任务栏独立适配分辨率、DPI 缩放、避让布局与水平位置偏移：

- 可通过 **右键 → 显示位置** 选择「所有显示器」、「仅主显示器」或任意已开启任务栏的副屏；所选副屏断开时自动回落主屏，重连后恢复，不覆盖原偏好。
- 某块显示器运行全屏游戏或视频时，仅暂停该显示器面板的渲染与布局探测，其余副屏面板继续实时刷新；退出全屏或取消截图覆盖层时无闪烁恢复。
- 发生重叠时自动寻找能容纳面板的空白区域，临时避让不会覆盖保存的位置偏好，恢复大屏后可恢复原位置。
- 同一任务栏的布局临时读取失败时，会保留最近一次有效布局并重试；分辨率、缩放或任务栏变化后重新读取。**空间不足或新布局尚未就绪时，该任务栏面板会暂时隐藏**，仍可点击托盘图标打开性能概览。

## 从源码构建

需要 Windows、PowerShell 和支持 C++20 的 **LLVM-MinGW UCRT x64** 工具链。构建脚本使用 `clang++` 与 `llvm-rc`，无需 Visual Studio 或 CMake。

### 1. 安装工具链

```powershell
winget install --id MartinStorsjo.LLVM-MinGW.UCRT -e
```

也可手动安装 [LLVM-MinGW](https://github.com/mstorsjo/llvm-mingw)，并将其 `bin` 目录加入用户或系统 `PATH`。

### 2. 编译

下载或克隆源码后，在项目根目录打开 PowerShell，执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

脚本会读取用户和系统 `PATH`，编译资源与 C++ 源码，并将结果输出到 `build\TaskbarMonitor.exe`。

### 3. 运行

```powershell
Start-Process -FilePath .\build\TaskbarMonitor.exe
```

CPU 温度使用的签名模块已嵌入 EXE，无需额外复制 `AMDFamily17.bin`；对应的 PawnIO 驱动仍需由系统另行安装。

## 项目结构

```text
.
├── build.ps1          # PowerShell 构建脚本
├── res/               # 图标、应用清单、资源与 PawnIO 签名模块
├── src/
│   ├── main.cpp       # 程序入口与单实例控制
│   ├── app/           # 主控制器、任务栏面板、托盘、概览与菜单
│   ├── collectors/    # CPU、GPU、内存、网络与金价采集
│   ├── core/          # 配置、主题与开机自启
│   ├── render/        # Direct2D / DirectWrite 绘制与窗口合成
│   └── taskbar/       # 任务栏布局读取、空白区域定位与避让
└── tests/             # 位置算法测试与真实任务栏布局检查
```

系统指标主要使用 Windows 原生 API：CPU 占用率通过 `GetSystemTimes` 获取，主频结合 `CallNtPowerInformation` 与 PDH 性能计数器计算，内存使用 `GlobalMemoryStatusEx`，网卡流量使用 `GetIfTable2`。金价请求使用系统 WinHTTP，任务栏控件边界通过 UI Automation 在后台读取。

## 常见问题

**程序已启动，但任务栏看不到面板？**

先检查托盘图标，确认程序正在运行。任务栏自动隐藏或可用空间不足都可能使面板暂时不可见。可以通过托盘打开概览，关闭金价列以减少宽度，或减少任务栏上的项目；调整位置后也可尝试“重置水平位置偏移”。

**CPU 温度或 GPU 数据不可用？**

CPU 温度需要受支持的 AMD Zen 处理器、已安装的 PawnIO 驱动和管理员权限。GPU 详细指标需要显卡及 NVIDIA 驱动接口支持。具体条件见上方的[指标与兼容性](#指标与兼容性)。

**配置没有保存？**

确认程序目录可写。建议放在当前用户有写入权限的普通目录，避免因目录权限导致 INI 文件无法写入。

**构建时找不到 `clang++` 或 `llvm-rc`？**

确认安装的是 LLVM-MinGW，并将其 `bin` 目录加入用户或系统 `PATH`。构建脚本会重新加载这两处路径，仅在当前终端临时添加路径不会保留。
