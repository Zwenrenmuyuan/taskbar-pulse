# Win11 任务栏系统负载监控（轻量化原生 C++ 版）

专为 Windows 11 设计的极简、低占用、高颜值任务栏状态栏工具。纯 Win32 + Direct2D / DirectWrite 实现，单文件运行。基本监控无需额外驱动或管理员权限；可选 CPU 温度复用已安装的 PawnIO 驱动，需要管理员权限。

## 特性
- **轻量运行**：单一可执行文件约 1.3 MB，无第三方运行时依赖；系统指标按设定周期采样，金价独立低频请求，任务栏图标边界在后台约每秒检查一次。
- **采集方式**：
  - **CPU**：占用率（`GetSystemTimes`）+ 实时主频（`CallNtPowerInformation` + 单计数器 PDH）
  - **CPU 温度（可选）**：AMD Zen 控制温度（Tctl，9950X 上为 Tctl/Tdie），通过已有 PawnIO 读取，随刷新周期采样。右键 → CPU 副行指标 → 显示 CPU 温度；概览面板同时显示温度与主频。无驱动或权限不足时温度不可用，其他监控正常运行。程序不安装驱动、不自动提权。
  - **GPU**：占用率、核心温度、已用/总显存（优先轻量 `nvapi64.dll`，兼容回退 `nvml.dll` / DXGI）
  - **内存**：已用 / 总物理内存（`GlobalMemoryStatusEx`）
  - **网络**：硬件网卡实时上传 / 下载速率（`GetIfTable2` 过滤物理硬件接口，避免虚拟过滤驱动翻倍统计）
- **国际金价**：通过 [Gold API](https://gold-api.com/faqs) 的免 Key 人民币接口获取国际现货价格，换算为元/克，独立一列显示。使用系统 WinHTTP，每 30 秒在后台请求一次；右键 → 显示国际金价可关闭显示与后续请求。托盘提示显示报价时间（本地时区），获取失败保留上次价格并标记“未更新”。这是国际现货换算价，与上金所 Au99.99、金店售价不同。
- **Win11 原生级视觉**：
  - DirectWrite 灰度抗锯齿 + OpenType `tnum` 等宽数字防抖动（数值跳变整行不晃动）
  - 支持 **Win11 微胶囊风** 与 **极致无框原生风** 一键切换
  - 自动跟随 Windows 11 任务栏 **浅色 / 深色** 主题，支持 Per-Monitor DPI v2 高分屏缩放
  - 全屏游戏/视频及任务栏自动隐藏时自动避让隐藏
- **便捷交互**：
  - **左键单击**：弹出/收起性能概览浮窗（含 48 秒历史折线图、详细显存/内存占比、本次会话流量及快捷切换按钮）
  - **右键单击**（状态栏或托盘图标）：完整菜单（切换风格、主题、进度条、CPU 副行显示、刷新频率、开机自启等）
  - **Alt + 左键拖动**：自由微调状态栏横向位置
  - **远程与分辨率切换**：跟随主任务栏当前的分辨率和缩放，读取应用图标、搜索、小组件及托盘的实际边界，优先保留手动位置，重叠时自动移到能容纳控件的空白区域。自动避让不覆盖已保存的偏移，恢复大屏后可恢复原位置偏好。同一任务栏的布局临时读取失败时保留最近一次有效位置并重试，避免托盘弹窗导致面板消失；分辨率、缩放或任务栏变化时重新读取。没有足够空间或新布局尚未取得时隐藏任务栏面板，仍可点击托盘图标查看概览。当前只显示在主任务栏。

## 编译方法
需要安装 `LLVM-MinGW`（`winget install --id MartinStorsjo.LLVM-MinGW.UCRT -e`）：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

生成产物位于 `build\TaskbarMonitor.exe`，配置自动保存于同目录 `TaskbarMonitor.ini`。

CPU 温度所用签名模块及许可证见 `res/pawnio/NOTICE.txt` 和 `res/pawnio/COPYING`，模块随资源嵌入 EXE。
